In Express.js, an Express Router is a built-in class used to create modular, mountable route handlers.
It is often described as a "mini-application" because it can perform middleware and routing functions 
just like a main Express application instance, but it cannot stand alone


Instead of cluttering your main server file (like app.js or index.js) with dozens of API endpoints, 
you use Express Router to split your routes into separate, organized files


Cookies: 

HTTP Cookies

An HTTP cookie is a small piece of data that a web server sends to a user's browser. 
The browser stores the cookie and sends it back to the server with subsequent requests.
Cookies help websites remember information about users across multiple HTTP requests.

Why Are Cookies Needed?

HTTP is a stateless protocol. This means that each request is independent, and the server does 
not automatically remember previous requests from the same client.

For example, consider an online shopping website:

You log in to the website.

You add a product to your cart.

You move to another page.

The website should still know who you are and what is in your cart.
